# JA 星光计划正式平台

这是与旧原型隔离的新一代正式平台工程。它以完整业务闭环为优先，保留了后续替换数据库、身份服务和对象存储的边界。

## 已实现

- 公共官网、实习机会检索与详情、成长内容中心
- 学生端：可视化总览、邮箱直投岗位、活动自动轮播与报名、图文/视频成长内容、简历上传与可编辑个人主页
- 企业端：岗位、活动、成长内容与企业资料的创建、编辑、删除和图片/视频上传
- 学生与企业账号：邮箱 + 密码注册登录、独立会话、身份固定、忘记密码三步流程
- JA 后台：独立管理密钥登录、密钥生命周期管理、统一审核、内容管理和审计日志；不出现在官网或公开角色入口
- 持久化个人/企业资料与报名状态、私有简历文件、公开媒体文件、服务端身份识别与审计记录
- JA 2026 品牌色系统、响应式桌面与移动布局

## 本地运行

```bash
npm install
npm run dev
```

默认从可用端口启动。生产构建与检查：

```bash
npm test
```

## 架构边界

- `app/`：公共官网、学生/企业工作台、隐藏运营后台和服务端接口
- `app/data.ts`：当前演示内容；正式内容由 CMS/后台管理接管
- `db/`、`drizzle/`：结构化数据模型与迁移
- D1：当前可部署的结构化数据适配器
- R2：简历等私密文件的对象存储适配器
- `.openai/hosting.json`：托管运行时绑定

公开页面允许匿名浏览。学生与企业在各自登录页使用邮箱和密码；一个邮箱只能绑定一个身份。账号密码使用带随机盐、按托管运行时上限分段执行的 PBKDF2-HMAC-SHA-256 保存，登录会话只在 HttpOnly Cookie 中传递。简历为私有文件，企业上传的图片/视频可在审核通过后公开展示。JA 后台使用可单独停用、恢复或永久撤销的管理密钥，关键操作均写入审计日志。

## 认证环境变量

复制 `.env.example` 并为每个环境单独配置。`AUTH_PEPPER`、三个 `AUTH_SEED_*` 和 `RESEND_API_KEY` 必须通过托管平台的 Secret 管理，不能提交到 Git。学生会话为 7 天，企业会话为 24 小时，JA 管理会话为 4 小时。

密码重置邮件通过 `lib/auth/mail.ts` 的适配器发送。当前实现为 Resend；未来迁移腾讯云时，只需替换适配器实现并保持 `sendPasswordResetMail` 接口不变。未配置 `RESEND_API_KEY` 与已验证发件地址时，界面完整保留，服务端明确返回“邮件服务正在配置中”，不会生成或暴露测试验证码。

## 后续兼容

正式业务模块按用户、凭据、会话、职位、申请、活动、报名、内容、审核、文件与审计拆分。若未来迁移到自有域名和服务器上的 NestJS + PostgreSQL，可保持页面、Cookie 契约和业务状态机不变，只替换数据库、邮件与对象存储适配层。
