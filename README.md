# JA 星光计划正式平台

这是与旧原型隔离的新一代正式平台工程。它以完整业务闭环为优先，保留了后续替换数据库、身份服务和对象存储的边界。

## 已实现

- 公共官网、实习机会检索与详情、成长内容中心
- 学生端：可视化总览、邮箱直投岗位、活动自动轮播与报名、图文/视频成长内容、简历上传与可编辑个人主页
- 企业端：岗位、活动、成长内容与企业资料的创建、编辑、删除和图片/视频上传
- JA 后台：隐藏且需登录的统一审核、内容管理和审计日志；不出现在官网或公开角色入口
- 持久化个人/企业资料与报名状态、私有简历文件、公开媒体文件、服务端身份识别与审计记录
- JA 2026 品牌色系统、响应式桌面与移动布局

## 本地运行

```bash
npm install
npm run dev
```

默认从可用端口启动。生产构建与检查：

```bash
npm test
```

## 架构边界

- `app/`：公共官网、学生/企业工作台、隐藏运营后台和服务端接口
- `app/data.ts`：当前演示内容；正式内容由 CMS/后台管理接管
- `db/`、`drizzle/`：结构化数据模型与迁移
- D1：当前可部署的结构化数据适配器
- R2：简历等私密文件的对象存储适配器
- `.openai/hosting.json`：托管运行时绑定

公开页面允许匿名浏览。当前公开体验通过浏览器生成的隔离体验身份写入云端 D1/R2；简历为私有文件，企业上传的图片/视频可在审核通过后公开展示。JA 后台通过 ChatGPT 登录保护且没有任何公开入口，正式启用时还应配置 JA 管理员邮箱白名单。

## 后续兼容

正式业务模块按用户、职位、申请、活动、报名、内容、审核、文件与审计拆分。若未来迁移到 NestJS + PostgreSQL，可保持页面和业务状态机不变，只替换数据与服务适配层。
