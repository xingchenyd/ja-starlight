# JA 星光计划正式平台

这是与旧原型隔离的新一代正式平台工程。它以完整业务闭环为优先，保留了后续替换数据库、身份服务和对象存储的边界。

## 已实现

- 公共官网、实习机会检索与详情、成长内容中心
- 学生端：总览、机会筛选与申请、申请进度、活动报名、学习中心、简历上传、认证成长档案
- 企业端：招募总览、职位生命周期、授权人才库、活动合作、内容共创、企业认证资料
- JA 管理端：运营数据、统一审核、用户与企业、职位、活动全周期、内容中心、审计日志
- 持久化申请/报名状态、私有简历文件存储、服务端身份识别与审计记录
- JA 2026 品牌色系统、响应式桌面与移动布局

## 本地运行

```bash
npm install
npm run dev
```

默认从可用端口启动。生产构建与检查：

```bash
npm test
```

## 架构边界

- `app/`：公共端、三端工作台和服务端接口
- `app/data.ts`：当前演示内容；正式内容由 CMS/后台管理接管
- `db/`、`drizzle/`：结构化数据模型与迁移
- D1：当前可部署的结构化数据适配器
- R2：简历等私密文件的对象存储适配器
- `.openai/hosting.json`：托管运行时绑定

身份只由服务端可信请求头识别，企业/学生角色可在首次建档时确定；JA 管理员不通过公开注册产生。公开页面允许匿名浏览，写操作要求登录（本地开发提供隔离的预览身份）。

## 后续兼容

正式业务模块按用户、职位、申请、活动、报名、内容、审核、文件与审计拆分。若未来迁移到 NestJS + PostgreSQL，可保持页面和业务状态机不变，只替换数据与服务适配层。
