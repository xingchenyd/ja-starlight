# JA 星光计划企业端精细化 Implementation Plan

**Goal:** 将企业端从功能集合升级为可持续运营的企业工作空间，覆盖企业认证、内容资产、报名审核、互动和经营概览。

**Architecture:** 保留现有会话、D1/R2、平台记录和审核接口；把企业端页面逐步抽离到 `app/workspace/enterprise`。所有写操作继续由服务端验证组织归属、版本和审核状态，草稿与正式发布严格分离。

## Task 1：企业工作台与状态口径

- 统一待办、发布状态、报名、互动、资料完整度和错误重试。
- 所有工作台卡片准确进入对应模块或对象，不保留无动作卡片。

## Task 2：机会、活动、内容发布中心

- 列表支持搜索、状态筛选、草稿、编辑、复制、归档和审核意见。
- 编辑器支持分步校验、自动保存、本地恢复、冲突提示、媒体预览与提交确认。
- 机会直接发布；企业活动与成长内容提交 JA 审核。

## Task 3：学生报名审核与导出

- 按活动、状态、关键词和日期筛选；单条与批量审核共用规则。
- 详情使用共享 SidePanel，明确联系方式、动态字段、审核意见和结果。
- 导出当前筛选结果，避免导出越权或隐藏数据。

## Task 4：互动管理

- 待回复/已回复队列、搜索、详情、回复、删除和失败重试。
- 回复身份明确为内容发布方，操作有保存状态和审计。

## Task 5：企业画像与成员安全

- 企业公开信息与内部联络信息分区，显示完整度、验证状态和学生端预览。
- 为后续域名、服务器、组织成员和角色权限保留稳定扩展点。

## Task 6：企业端阶段验收

- lint、build、全量测试和企业端全部稳定 URL 浏览器验收。
- 检查空状态、网络失败、键盘焦点、减少动态和 1024px 布局。
