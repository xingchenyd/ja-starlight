## 内测数据清理

`scripts/cleanup-samples.mjs` 为显式维护命令，不在应用启动或日常请求中执行删除。

识别范围：固定预置记录ID、已知学生/企业内测账号、保留的测试域名账号、旧演示所有者、明确的自动验收ID，以及相关报名、收藏、日程、成长记录、队伍、互动、通知、会话和私有文件。

处理步骤：

1. 使用新版本代码，确认运行配置没有启用 `AUTH_ENABLE_SAMPLE_ACCOUNTS`。保持原有认证密钥和管理员入口。
2. 暂停正式写入，在维护窗口停止应用进程。创建包含数据库、文件和配置的完整备份，检查完成标记。
3. 运行只读清理计划，核对数量及 `reviewCandidates`。标题含“测试”的真实发布不会因关键词被自动删除；来源不确定的条目须先核实。
4. 使用与计划完全匹配的备份执行清理。任何数据库变化、完整性失败或真实数据变化都会中止或回滚。
5. 测试文件元数据移至该备份的隔离目录；文件实体仅在没有其他引用时隔离。真实资料、真实企业上传和管理员密钥保留。
6. 重启并检查目录、三端入口、管理员登录、真实数据读取、排名及日志。删除的样例不能再次被自动创建。

命令示例（备份路径必须替换为实际已完成的快照目录）：

```sh
node --experimental-sqlite scripts/cleanup-samples.mjs /srv/star-plan/data --plan /root/star-plan-cleanup-plan.json
node --experimental-sqlite scripts/cleanup-samples.mjs /srv/star-plan/data --apply /root/star-plan-cleanup-plan.json /srv/star-plan/snapshots/ACTUAL_COMPLETED_SNAPSHOT
```
