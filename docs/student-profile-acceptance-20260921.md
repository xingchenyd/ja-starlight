# 学生资料修复验收（2026-09-21）

## 修复范围
- 不再用内置姓名、学校等填充空资料；异步加载完成后显示当前账号实际资料。
- 弹窗焦点管理不再因输入和关闭回调变化而重新执行，连续输入保持焦点。
- PDF 在浏览器本地解析，识别实际存在的资料，确认后保存；未识别的字段保留原值。
- 已上传 PDF 支持重新识别，保存失败保留窗口与编辑内容，不显示假成功。
- 服务端检查字段、简历所属账号、重复档案和版本冲突。
- 仅归档完全未修改的已知种子个人资料；保留用户修改和服务器数据库、上传文件。

## 验收证据
- lint、默认构建、Node 自托管构建通过；127 项自动测试通过。
- 隔离的本地持久数据库：空账号、保存重读、重复档案、跨账号访问、版本冲突通过。
- 浏览器连续输入两段姓名未失焦；保存、刷新、重新登录与进程重启后资料仍存在。
- 英文及中文合成 PDF 均识别 9 项字段；中文包括姓名、学校、专业、年级、技能、奖项、自我介绍、电话、邮箱。
- 无效邮箱保存被拒绝且窗口保留；更正后保存成功。
- 第二个空账号不显示首个账号的资料或内置人物信息。

## 边界
识别是文本 PDF 的本地规则提取，不包含扫描图片 OCR。无法读取、加密或缺失字段时明确提示并允许手动填写，不生成虚构个人信息。生产部署不迁入本地验收账号或数据。
