# 星光计划竞赛流程与一致性改造验收

日期：2026-09-22（北京时间）。生产发布目录：`/srv/star-plan/releases/20260922-challenge-workflow`。

## 已交付

- 企业与运营发布端共享竞赛任务书编辑器，支持循环经济参考结构、资格、成果要求、评审规则、兑现条件、日期及团队人数。
- 学生独立报名通过后建队或凭定向邀请码加入。队长提交，主办方评审、退回补交或记录获奖/推荐。
- 终审后每位成员获得默认私密的认证经历。报名通过不等于竞赛完成。
- 不同企业之间、企业与运营自办活动之间隔离。并发最后名额、重复提交、旧版本覆盖及活动规则变化均有服务端检查。
- 个人主页“一句话介绍”；Logo 外框、列表卡片、标题和摘要布局统一；运营后台去除旧主体 Logo。
- 后台登录保留原页面去向，仅接受白名单内站内地址，拒绝外部跳转。

对部署前后的关键表逐条核对原记录 ID 均存在：用户 6、业务记录 40、报名 18、成长经历 5、媒体记录 2。该核对证明本次发布没有丢失这些原记录，不是对未来所有故障的无丢失保证。
