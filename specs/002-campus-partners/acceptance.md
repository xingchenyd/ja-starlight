# 星光伙伴本地验收

本地预览运行在 [3018 端口](http://localhost:3018/)。使用独立 SQLite 数据库，测试账号和数据保存在本机。正式站的操作仅涉及技术管理密钥轮换。

| 验证方式 | 实测结果 |
| --- | --- |
| TypeScript、ESLint、默认构建及 Node 构建 | 通过 |
| 自动化测试 | 152 项通过 |
| 本地 HTTP 跨角色验收 | 13 组通过，包含校外激活、本校学生名册、跨校越权、自审、自评、报名快照、成果认证、撤职与交接 |
| 浏览器 | 学生登录后进入校园工作台，查看报名原题和回答，下载 CSV，连续输入标题和正文，新增开放式问题并保存草稿 |
| 重启并重新登录 | 已读回名册、原题与回答、已通过报名、任职与撤销记录、竞赛认证、浏览器草稿和校外运营授权 |
| SQLite | 完整性检查通过，外键检查未发现违规 |

本地流程可从学生端进入「我的校园」，使用星光伙伴账号打开校内名册、发布和报名工作区。独立业务工作台位于 [运营登录](http://localhost:3018/operations/login)。技术负责人从 [管理登录](http://localhost:3018/ja-login) 进入「学校与业务授权」。

HTTP 场景使用 `scripts/campus-acceptance-http.mjs`。仅对专用测试数据库执行，配置文件路径通过 `STARPLAN_ACCEPTANCE_CONFIG` 指定。验收脚本会创建带唯一批次号的本地账号与活动。
